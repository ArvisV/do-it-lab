# Do It Lab

Do It Lab ir hobiju un mācību projektu pārvaldības tīmekļa platformas prototips, kas tiek izstrādāts bakalaura darba ietvaros.

## Mērķis

Izveidot platformu, kurā lietotāji var publicēt savus hobiju un mācību projektus, dokumentēt to izstrādes gaitu un dalīties pieredzē ar citiem lietotājiem.

## Plānotās tehnoloģijas

- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- Prisma

## Projekta statuss

Projekta sākotnējās izstrādes un vides sagatavošanas posms.
